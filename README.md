## Функциональность

### Управление записями (CRUD)
- **Create** - Добавление новой записи с валидацией данных
- **Read** - Просмотр всех записей и поиск по фильтрам
- **Update** - Обновление существующих записей
- **Delete** - Удаление записей с подтверждением
- **Find** - фильтрация записей по указанным полям. 
  - Поддерживается поиск по одному или нескольким критериям (например, `age=25` или `name="John", age=25`)
  - Если поле отсутствует у записи - запись НЕ будет включена в результаты
  - Если указано поле, которого нет в таблице - результатом будет пустой список

### Управление таблицами
- Создание новых таблиц
- Просмотр списка всех таблиц
- Выбор активной таблицы для работы

### Дополнительные возможности
- **Сортировка** - записи сортируются по указанному полю (по возрастанию/убыванию)
  - Поддерживается сортировка как по пользовательским полям, так и по служебному полю `id`
  - Если у записи отсутствует поле для сортировки, она помещается:
    - В конец списка при сортировке по возрастанию
    - В начало списка при сортировке по убыванию
  - Это гарантирует, что сортировка всегда выполнится без ошибок, даже если структура записей неоднородна
- **Очистка** таблицы
- **Валидация** возраста (0-150 лет)

### Файловое хранение (JSON)
- **Сохранение данных на диск** - после завершения программы записи не теряются
- **Два режима работы** - In-Memory (данные не сохраняются) и Файловая БД (данные сохраняются в JSON)
- **Формат хранения** - каждая таблица сохраняется в отдельный JSON-файл
- **Автоматическая загрузка** - при запуске данные восстанавливаются из файлов
- **Атомарная запись** - защита от повреждения файлов при ошибках
- **Восстановление таблиц** - повреждённые JSON-файлы обрабатываются без потери остальных данных

### Файловое хранение (CSV)
- **Альтернативный формат хранения** - данные сохраняются в CSV-файлах
- **Совместимость с Excel** - файлы можно открывать в Excel, Google Sheets
- **Компактный размер** - CSV-файлы занимают меньше места
- **Поддержка всех типов данных** - строки, числа, булевы значения
- **Динамические заголовки** - автоматическое добавление новых полей
- **Тот же интерфейс** - полностью совместим с JSON и In-Memory версиями

### Обработка ошибок файловой системы
- **PermissionError** - проверка прав доступа к файлам и директориям
- **JSONDecodeError** - обработка повреждённых JSON-файлов
- **OSError** - перехват ошибок файловой системы
- **Откат изменений** - при ошибке сохранения данные в памяти не меняются
- **Восстановление next_id** - корректный расчёт из максимального ID записей
