## Функциональность

### Управление записями (CRUD)
- **Create** - Добавление новой записи с валидацией данных
- **Read** - Просмотр всех записей и поиск по фильтрам
- **Update** - Обновление существующих записей
- **Delete** - Удаление записей с подтверждением

### Управление таблицами
- Создание новых таблиц
- Просмотр списка всех таблиц
- Выбор активной таблицы для работы

### Дополнительные возможности
- **Сортировка** записей по любому полю (по возрастанию/убыванию)
- **Очистка** таблицы
- **Валидация** возраста (0-150 лет)
- **Проверка** уникальности ID

## Запуск приложения

### Требования
- Python 3.12 или выше

### Команда для запуска
```
python -m src.db.tui

```
